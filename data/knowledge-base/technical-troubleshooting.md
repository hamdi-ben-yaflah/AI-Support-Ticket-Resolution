# Common technical troubleshooting

## Initial checks

Confirm the affected feature, exact error message, approximate time, browser or app version, and whether the problem affects one user or several. Ask the customer to retry in a private browser window and disable browser extensions temporarily.

## Connection and cache

The customer may sign out, clear site data for the product domain, restart the browser, and sign in again. They should also test another network when practical. Do not tell them to disable security software permanently.

## Reproducible errors

If the issue persists, collect safe reproduction steps and a screenshot with personal data removed. Do not request access tokens, passwords, private keys, or unredacted network logs.
